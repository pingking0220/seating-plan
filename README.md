# 🪑 排座位系統

多元教室座位安排工具 — 給國小老師的純前端網頁應用。開網址就能用，**所有資料只存在你電腦的瀏覽器裡，不會上傳任何伺服器**。

🌐 **線上使用：https://pingking0220.github.io/seating-plan/**

## 功能

- 📥 **Excel 名單匯入** — 從 Excel 直接複製貼上或選檔，自動猜欄位；含「班級」欄的全學年名單可一次拆成多個班級
- 🏫 **多元教室佈局** — 9 種範本（排排坐／雙人併桌／四人島／六人島／ㄇ字型／圓圈／電腦教室／實驗室／考試模式）＋快速產生器＋自由拖曳編輯，座位屬性（前排／靠窗／靠門／走道側）依黑板門窗位置自動推導
- 🎲 **規則式自動排位** — 14 條可調權重規則：需前排、輪椅無障礙座、易分心遠離門窗、不可相鄰、異質分組、公平輪替…點任何座位都能看到「為什麼坐這裡」
- ✋ **手動微調** — 點選入座、交換、鎖定座位；衝突清單即時更新
- 📌 **公平輪替** — 封存歷史後，下次自動排位避開同座位、同鄰居
- 🖨️ **列印匯出** — 老師視角／學生視角一鍵翻轉，列印 PDF、PNG、Excel
- 🔑 **佈局分享碼** — 一串文字傳給同事就能匯入教室佈局，資料不經伺服器
- 💾 **備份還原** — 一鍵 JSON 備份，逾期未備份自動提醒

## 開發

```bash
npm install
npm run dev      # http://localhost:5199
npm run test:run # 單元測試
npm run build    # 正式建置
```

技術棧：Vue 3 + Vite + Pinia + SheetJS + idb-keyval（IndexedDB）+ lz-string。核心邏輯（`src/core/`）全部是零框架依賴的純函式。

## 隱私

學生姓名與需求標籤等所有資料只存在使用者瀏覽器的 IndexedDB，本專案沒有後端、沒有資料庫伺服器、沒有任何遙測。
